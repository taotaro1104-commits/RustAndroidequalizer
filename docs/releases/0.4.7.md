# Rust EQ 0.4.7

エコーの調整機能を追加しました。「空間」画面の「エコー」で、量（1〜100%）、間隔（20〜1000 ms）、繰り返し（フィードバック 0〜85%）を調整できます。

- 左右それぞれのディレイにフィードバックをかけた単純なエコーです。繰り返しのたびに高域が少し丸くなり、間隔や量を動かしても音が途切れにくいようにしています。
- オフにすると残響を消去し、再度オンにしても古い音は再生されません。バイパス中は無効です。アプリ内のRust DSPだけに適用し、他アプリ向けのEQでは使えません。
- 設定JSONにエコーの値を保存します。以前のJSONはエコーなしとして読み込めます。標準プリセットを選ぶとエコーはオフに戻ります。
- 0.4.6の31バンド用プリセットとBASS 200%はそのまま含みます。

検証：Rustワークスペースの全テスト成功（エコーの新テスト5件、リアルタイム無確保テストを含む）。Android 15エミュレータでandroidTest全44件が成功。署名済みrelease APKのv2/v3署名と16 KB整列を確認しました。実機での確認、Lint、聴感評価は行っていません。
