# Rust EQ 0.4.5

YouTube Musicなど、選択した他アプリの曲名・アーティスト・再生状態・再生位置を「音づくり」と「再生情報」に表示します。従来はアプリ内プレーヤーの測定値だけを表示していました。

「ツール → 他アプリにもEQ」でYouTube Musicを選び、「再生情報の表示を設定」からAndroidの通知アクセスを許可してください。YouTubeとYouTube Musicは別の対象です。Android13の制限付き設定についても画面で案内します。

- 実際のMediaSessionを観測し、曲変更・一時停止・再開を追従。再生中だけ位置を補間し、不明な長さや位置は不明として表示します。
- 選択解除・セッション終了・アクセス取り消しで曲情報を消去。通知本文の解析や曲履歴の保存は行いません。
- EQ接続は曲情報と別に判定し、キャスト先での再生にも注記。アプリ内Rust DSP測定値を他アプリ音声の測定値として表示しません。

Android13の別UIDプレーヤーによる全42件、単体15件、Rust35件、日英リソース2件、プロセス終了を挟む設定復元を確認。旧版0.4.4で外部曲名が表示されないことを再現し、更新版での表示・曲変更・権限取り消しと再許可・設定画面への遷移を検証しました。同一鍵の署名済み0.4.4からの更新、署名版での曲名とEQ接続、プロセス終了後の曲情報再取得、両Lint・v2/v3署名・16KB整列も確認しました。

現行YouTube Musicクライアント、利用者端末、arm64実機での動作は未確認です。MediaSessionを公開する別UID fixtureの成功をYouTube Music実機での成功とは扱っていません。専用AVDは試験不要なGoogleサービス・画面アニメーションを停止した環境です。
