# Rust EQ 0.4.2

対象アプリを選択して保存し、未接続なら「接続」で対象のプレーヤーを開けます。対応する音声セッションへの再接続、選択解除時の解放、待ち受け設定の保存と端末起動後の復元に対応しました。日本語・English表示とオリジナルアイコンも含みます。

- Android10以上、arm64-v8a / x86_64、versionCode6。
- 既存0.4.1署名版からの更新インストールを確認。署名証明書は変更していません。
- 22件のAndroid instrumentationテスト成功、スキップなし。debug / releaseのLintは問題なし。
- 通知を拒否しても対象アプリへのタップ接続を確認。端末起動後、画面を開く前に待ち受けが復元されることを一時エミュレーターで確認。
- Rustの全workspaceテストとAndroidのdebug / releaseビルドを再確認。
- APKと署名・検証情報は[検証記録](0.4.2.json)を参照。

「他アプリにもEQ」は対応アプリの音声セッションにAndroidの端末EQを適用する機能です。任意のアプリの音声をRust DSPへ強制転送することはできません。詳しい操作と制約は[外部EQの説明](../external-eq.md)を参照してください。

配布パッケージには署名APK、ソース、ライセンス、実画面、検証記録を含めます。生成物と秘密署名鍵はGitへ含めません。配布先のGoogleドライブへのアップロードは別途必要です。
