# Rust EQ 0.4.6

31バンドEQ向けの標準プリセット11種類を追加し、疑似BASSの強さを最大200%まで設定できるようにしました。

- 「プリセット → 31バンド用プリセット」から、フラット／ロック／クラシック／ポップ／ジャズ／ボーカル／アコースティック／エレクトロニック／クリア／ベースブースト／メガベースを選べます。選ぶとEQが31バンド（20 Hz〜20 kHzの1/3オクターブ）になります。
- ベースブースト（疑似BASS 100%）とメガベース（疑似BASS 150%）は、超低域〜低域のEQと疑似BASSを組み合わせた強い低音向けです。
- 疑似BASSの強さを0〜100%から0〜200%へ拡大。100%を超える値は倍音を比例して強く加えます（上限は200%、最終リミッターは従来どおり）。以前の設定JSONはそのまま読み込めます。
- 既存の10バンド16プリセットは変更していません。

検証：Rustワークスペースの全テスト成功（200%の比例・上限クランプの新テストを含む）。アプリ本体とandroidTestのKotlinコンパイル、署名済みrelease APKのv2/v3署名・16 KB整列を確認しました。Android 15エミュレータでandroidTest全43件が成功しました（初回実行では外部プレーヤー連携の11件が環境状態により失敗し、再実行で成功）。実機での確認、Lint、聴感評価は行っていません。
