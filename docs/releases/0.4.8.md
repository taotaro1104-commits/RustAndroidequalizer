# Rust EQ 0.4.8

聴き比べ・音色合わせ・音作りのツールを追加しました（詳細は [聴き比べ・音色合わせツール](../listening-tools.md)）。

**聴き比べと音色合わせ（ツールタブ）**
- 音量をそろえたA/B比較とABXテスト（当てずっぽうで当たる確率を表示）。
- お手本の曲に音色を近づける（31バンドを自動設定、元に戻せます）。
- 自動プロファイル（曲 > 夜間 > Bluetooth・有線・スピーカーの順で切り替え）。
- 聴力テストによる個人補正（簡易的なセルフチェックで、医療用ではありません）。
- スピーカーと部屋の校正（マイクで測定して控えめに補正）。
- 音の共有（`rusteq1:` のテキストリンク。取り込みは確認ダイアログ経由）。

**サウンド**
- 音量連動ラウドネス（端末の音量が下がると低域・高域を自動で補う）。
- テンポ同期エコー（曲のBPMを検出して音符の長さに合わせる）。
- ルームリバーブ（FDN）、ハーモニック・エキサイター、ダイナミック低音EQ。
- True Peak リミッター（約1 msの先読みと遅延。既定でオン、画面でオフにできます）。

**変更点と注意**
- **マイクの録音権限（RECORD_AUDIO）を追加しました。** 「スピーカーと部屋に合わせて校正」を押したときだけ許可を求めます。音声はメモリ上で解析するだけで、保存も送信もしません。許可しなくても他の機能は使えます。
- 0.4.6 の英語文字列の書式エラー（Lintで検出）を修正しました。
- 設定JSONに新しい項目を追加しました。以前のJSONはそのまま読み込めます。
- 未対応: QRコードでの共有、同梱のヘッドホン別プロファイル検索。

検証：Rustワークスペースの全テスト52件成功（新しいDSPのテスト11件を含む）。JVM単体テストとLintは成功。Android 15エミュレータでandroidTest全54件が成功。署名済みrelease APKはv2/v3署名を確認し、0.4.7と同じ証明書です。実機での確認と聴感評価は行っていません。エミュレータのマイクは無音のため、部屋の校正は「結果が出るか、エラーを表示して終わること」だけを確認しました。
