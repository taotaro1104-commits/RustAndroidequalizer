# Rust EQ のオリジナルアイコン

「Curve R」は、音質カーブを流れるような **R** にした、このアプリ用に描いたマークです。アンバーの丸は音を調整するコントロール点を表します。文字を小さく配置せず、ホーム画面でも形を見分けられるようにしています。

- アプリと同じブルー `#4056CE`、白 `#FFFFFF`、アンバー `#FFD08A`。
- [SVG原稿](rusteq-icon.svg)／[1024px PNG](rusteq-icon.png)。
- AndroidのAdaptive Iconは108dpの前景・背景を分離し、中心66dpの安全領域にマークを収めています。
- Android 13以降のテーマアイコン用に、別の単色前景を用意しています。
- アプリ上部にも同じマークを使っています。画像生成サービスや素材サイトのアイコンは使用していません。

SVGとAndroid VectorDrawableの曲線は同じ形です。色のあるチューニング点は、単色表示では白になります。配布はリポジトリのライセンスに従います。

## OGP画像

[Rust EQ OGP（PNG・1731×909px）](rusteq-ogp.png) は、新しいRアイコン、アプリ名、日本語のコピー、ヘッドホンと音質カーブのイラストを組み合わせた共有用画像です。組み込み `imagegen` で制作し、生成されたPNGをそのまま保存しています。[制作プロンプト](rusteq-ogp-prompt.md) も同梱しています。
