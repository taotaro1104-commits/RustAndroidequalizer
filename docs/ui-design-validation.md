# カジュアル UI 改善の検証

対象：Android ネイティブアプリ、0.4.0 の UI 改善。2026-11-10。

白と淡いブルーを基調に、青を音づくり、オレンジを疑似 BASS、緑を空間表現に使いました。音づくり・空間・ツールの3画面に分け、標準16プリセットに各バンドの強弱を表す曲線を付けています。詳細な PEQ、保存・削除、AutoEQ / JSON 入出力、測定 CSV、HRTF / IR、外部セッション EQ、再生情報の操作を引き継いでいます。

実装は `ui/AudioApp.kt`（画面と操作）、`ui/AudioVisuals.kt`（ベクターアイコン・曲線・配置図）、`ui/AudioTheme.kt`（配色・文字）に分けています。新しいランタイム依存はありません。音声エンジンは変更していません。

検証結果：

- `assembleDebug` / `assembleRelease` / `assembleDebugAndroidTest` / `lintDebug` / `:session-player:assembleDebug` 成功。arm64-v8a / x86_64 の native link を確認。Lint は No issues found。
- Rust workspace 全35テストと整形チェックが成功。
- 新しいナビゲーションテストは、変更前の画面で「空間」が見つからず失敗することを確認してから実装。
- Android 計装テストは全13件成功（0 failed / 0 ignored）。画面切り替え、ボーカル選択、詳細調整の開閉状態・設定の保持、未読み込み時の再生リスト復帰を新たに検証。既存の native 再生・サービス・外部セッションテストも成功。詳細調整の検証には実タップとページ余白の縦スワイプを使う。
- API 35 の一時エミュレーターで、通常の約411 dp幅、320 dp幅、320 dp幅かつ文字サイズ200%、約1066 dpのタブレット幅を撮影・確認。文字は折り返し、ページ本文は縦スクロールする。大きな文字ではヘッダーの補助文を省き、再生ボタンを横幅いっぱいに配置する。
- 主要な文字色のコントラスト比：本文12.95:1、補助文4.88:1、低音5.14:1、空間5.38:1、主ボタン6.10:1。
- 独立したコードレビューで、未読み込み時の再生リスト復帰とページ内状態の破棄を指摘。再生・クリア操作を戻し、SaveableStateHolder で詳細調整・低音の復元量・ページ内スクロールを保持するよう修正。

[画面の原本](screenshots/README.md)の09〜12を参照してください。大文字ラベル、常時アニメーション、実測に見せかけた波形は使用していません。プリセットの小さな曲線はバンド設定、メイン曲線は EQ とプリアンプの静的な応答です。

実機での見え方、音質、長時間の性能評価は今回の確認範囲に含みません。
