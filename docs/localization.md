# 日本語・English

Rust EQ 0.4.1は、日本語と英語の表示に対応します。端末で設定した優先言語に応じて切り替え、対応言語が含まれない場合は英語で表示します。

Android 13以降では、端末の **設定 → アプリ → Rust EQ → 言語** から、このアプリだけの表示言語を選べます。端末によって設定項目の名前や場所は異なります。Android 10〜12では端末の言語設定に従います。

## 対応範囲

- 音づくり・空間・ツール、各ダイアログと読み上げ用の説明。
- 標準16プリセットの表示名と説明。
- 再生通知・外部EQ通知、通知チャンネル名、操作ボタン。
- 設定保存・ファイル取り込み・最適化・セッション接続のメッセージとエラー。

ファイル名、自分で付けたプリセット名、外部ライブラリやOSから返る技術的なエラー詳細は原文で表示します。エラーの案内文は現在の言語で表示します。

## 保存済みの音について

言語を切り替えても、プリセットID・保存名・JSONのキーや数値形式は変わりません。例えば「ボーカル」は英語では「Vocal」と表示しますが、適用するEQ設定は同じです。保存データの移行は不要です。

## 実装と検証

英語は `res/values/`、日本語は `res/values-ja/` に配置しています。アプリ言語は `res/xml/locales_config.xml` で公開します。状態には翻訳済み文字列を保存せず、`UiText`でリソースIDと引数を保持し、表示時のContextで解決します。

```powershell
python tools/check_localization.py
```

この検査は、対応言語の宣言、翻訳の欠落・重複、書式引数の互換性を確認します。Androidのリソース選択、言語切り替え後のメッセージ、プリセット互換性、実画面の切り替えは `LocalizationTest` で検証します。
