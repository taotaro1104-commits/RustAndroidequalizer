# 標準プリセットと疑似BASS

0.4.0で16種類の標準プリセットと疑似ウーファー処理を追加しました。root権限・録音権限は不要です。

## 標準プリセット

EQ画面のプリセットメニューから選択します。各プリセットは10バンドPEQとpreamp、コンプレッサー、Stereo Wide / Crossfeed、疑似BASSの設定をまとめて適用します。読み込んだSOFA / IRの選択は別の設定です。選択後に各項目を編集し、独自プリセットとして保存できます。

| プリセット | 調整の狙い | 追加処理 |
|---|---|---|
| フラット / Flat | 周波数バランスの比較基準 | なし |
| ウォーム / Warm | 低音の厚み | なし |
| ベースブースト | 低域をEQで強調 | なし |
| ディープベース | 特に低い帯域を強調 | なし |
| 疑似ウーファー | 倍音による低音感 | 疑似BASS 55%、110 Hz |
| ボーカル | 声の帯域 | なし |
| クリア / Treble | 高音の輪郭 | なし |
| ロック | 低域・高域のメリハリ | なし |
| ポップ | 低音と声のバランス | なし |
| ジャズ | 低域の厚みと輪郭 | なし |
| クラシック | 穏やかな低域・高域 | なし |
| アコースティック | 弦や声の存在感 | なし |
| エレクトロニック | 低音のリズムと高域 | なし |
| ポッドキャスト | 低域を抑え、声を中心に | Compressor −22 dB、2.5:1 |
| ナイト | 音量差と低音を抑える | Compressor −28 dB、5:1 |
| ゲーム | 中高域と左右の広がり | Stereo Wide 1.4 |

中心周波数は31.5 / 63 / 125 / 250 / 500 / 1000 / 2000 / 4000 / 8000 / 16000 Hz、Qは1.1です。合成応答のピークを44.1 / 48 / 96 kHzで調べ、少なくとも6 dBのプリアンプ減衰と追加の余裕を設けます。任意音源のtrue peakやクリップ防止を保証する値ではありません。

## 31バンド用プリセット

プリセットメニューの「31バンド用プリセット」から選びます。選ぶとEQが31バンド（20 Hz〜20 kHzの1/3オクターブ、Q 4.3）になります。フラット / ロック / クラシック / ポップ / ジャズ / ボーカル / アコースティック / エレクトロニック / クリア / ベースブースト（疑似BASS 100%）/ メガベース（疑似BASS 150%）の11種類で、プリアンプは10バンド版と同じ方法で自動設定されます。

## 疑似BASS

BASSパネルで有効化し、量を1〜200%（100%超は倍音をさらに強く加える強化域）、低域の抽出周波数を60〜180 Hzで調整します。オフ時の量は0です。

通常のベースブーストは低域そのものを増幅します。疑似BASSは低域から主に偶数次の倍音を作り、低い周波数を出しにくい機器でも低音を感じやすくする処理です。実際のウーファーの振動や超低音出力は再現しません。効果は音源と再生機器によって変わります。

処理順は preamp → PEQ → 疑似BASS → compressor → stereo / HRTF / reverb → limiter。左右共通の低域を抽出し、soft full-wave shaping、DC除去、帯域制限を通した倍音を同じ量で左右に加えます。設定変更は既存の20 msクロスフェードを通ります。追加のlookaheadはありません。

この処理はアプリ内のRust DSPに適用します。他アプリの音声セッションに接続するAndroid Equalizerでは再現しません。周波数応答グラフはPEQとpreampの静的応答で、非線形な倍音生成は表示しません。

## 保存と互換性

疑似BASSの量は0〜2.0（0〜200%）です。以前の範囲（0〜1）で保存したJSONもそのまま読み込めます。

JSONはversion 2とし、virtualBassAmountとvirtualBassHzを保存します。version 1の読み込みでは既定で無効 / 110 Hzとなります。JNIは既存102要素形式も受け入れ、新しい104要素形式の末尾に量・周波数を追加しています。

## 検証

Rustテストで60 Hzから120 Hzの倍音生成、量の変化、高域への影響、左右差の維持、bypass、DC・異常値を検証します。既存の可変ブロック・リアルタイム確保/解放検出テストでも疑似BASSを有効にしています。

Android instrumentationでは16プリセットの識別子・応答・JSON往復、旧JSON・JNI形式、入力範囲を検証します。実機での聴感評価は別途必要です。
